# 变更请求面板演示（临时文件，PR 关闭后可删）

这个文件只用来给 DSH 的「变更请求与工作树」插件跑一遍真实链路：

1. 在独立工作树里改文件（本次就是这个文件）；
2. `gh pr create --draft` 建一个 draft PR；
3. 回到 DSH 会话，标题栏按钮打开面板，确认这个 PR 自动出现；
4. 在「变更」视图里选一行写评论 → 「添加到输入框」→ 让 agent 按引用改。

第 4 步的评论示例（给面板用）：这一行的行末应该加一句「演示完成后关闭本 PR」。← 面板评论「演示完成」已按引用改到本行。
5. 演示完成：面板的行内评论「演示完成」经「添加到输入框」作为引用进入会话，agent 据此改了这一行，并把第 5 步加进来（push 后面板「变更」应显示 +11）。
